HOW IT WORKS

AI думает.
LifeLog отвечает за данные.

Ключевой принцип проекта — разделение ответственности. Модель работает с естественным языком и выбором инструмента. Сервер отвечает за валидацию, ownership, транзакции и детерминированную работу с PostgreSQL.

01Ты говоришь«Сколько я потратил на табак?»
02ChatGPT выбирает Toolquery_finance(...)
03LifeLog выполняет запросPostgreSQL → результат
04AI показывает ответ«За месяц — 6 400 ₽»
MCP TOOLS

Инструменты, которые уже работают.

Имена сохранены как в сервере, чтобы страница была полезна и обычному пользователю, и разработчику.

Memory4 tools
remember

Высокоуровневое сохранение общих воспоминаний: фактов, событий, мыслей, идей и наблюдений.

create_memory

Создание структурированной записи памяти.

update_memory

Изменение собственной записи памяти по ID.

delete_memory

Удаление собственной записи памяти по ID.

Finance6 tools
create_finance_event

Запись расходов и доходов со структурированными позициями, категориями, суммами и валютой.

update_finance_event

Изменение метаданных финансового события.

update_finance_item

Изменение отдельной позиции с автоматическим пересчётом общей суммы.

delete_finance_item

Удаление позиции с пересчётом итоговой суммы.

delete_finance_event

Удаление события и всех его позиций.

query_finance

Детерминированная аналитика: суммы, транзакции, категории, места, статистика и сводки.

Personal Telegram12 tools
telegram_connect

Подключение личного аккаунта через телефон/код или официальный QR-login, включая 2FA.

telegram_status

Проверка состояния подключения личного Telegram.

telegram_disconnect

Отключение личного Telegram-аккаунта.

telegram_search_contacts

Поиск по телефону, имени, username или Telegram ID.

telegram_add_allowed_contact

Явное добавление диалога в per-user allowlist.

telegram_list_allowed_contacts

Просмотр разрешённых контактов.

telegram_remove_allowed_contact

Удаление контакта из allowlist.

telegram_get_messages

Чтение истории конкретного разрешённого диалога.

telegram_get_new_messages

Получение новых входящих сообщений из активных мониторов.

telegram_start_monitoring

Включение мониторинга разрешённого диалога.

telegram_stop_monitoring

Остановка мониторинга.

telegram_send_message → telegram_confirm_send

Подготовка и отправка сообщения только после явного подтверждения.

SECURITY BY DESIGN

Данные принадлежат тебе.

LifeLog разделяет пользователей на серверной стороне. Память и финансы всегда привязаны к владельцу запроса.

OwnershipКаждая запись scoped к user_id.
Telegram allowlistКонтакт нельзя читать или писать только потому, что он есть в Telegram.
Confirmed sendingИсходящее сообщение сначала превращается в зашифрованный pending request.
Transactional dataФинансовые операции и уведомления проходят через серверную бизнес-логику и транзакции.
